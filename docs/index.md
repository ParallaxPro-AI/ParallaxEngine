# ParallaxEngine

ParallaxEngine runs 2D and 3D browser games authored as Python scripts, JSON data,
and HTML/CSS panels. Its tools support both manual development and coding agents.

- [Getting started](getting-started.md): install, create a game, and play it.
- [Cheatsheet](cheatsheet.md): the most-used APIs and file formats on one page.
- [Engine concepts](concepts/README.md): understand how game code and data fit together.
- [Making a game look good](concepts/visuals.md): terrain, foliage, sky, weather, water, effects, generated buildings, and a catalog of engine capabilities.
- [Examples](examples.md): choose an existing game to learn from.
- [Command line](cli.md): create, check, test, build, and edit projects.
- [API reference](reference/README.md): look up types and signatures, generated from the SDK.
- [Error catalog](errors/README.md): look up diagnostic codes reported by the engine.
