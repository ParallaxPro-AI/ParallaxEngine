read the topics your game needs. The [cheatsheet](../cheatsheet.md) summarizes
them on one page; exact signatures live in the [API reference](../reference/README.md).

| [World](world.md) | Prefabs, placements, scenes, and plugins |

| [Parallax Python](parallax-python.md) | Language support and restrictions |
